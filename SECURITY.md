# Security Policy

## Supported versions

PARA is in preview (0.x). Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: go to the Security tab of this repository and choose "Report a vulnerability." You will receive an acknowledgment within 5 business days.

Reports about the skill's own behavior are in scope, including assessed artifacts that manipulate the assessor, unsafe rendering of report output, and validator logic that understates risk.
